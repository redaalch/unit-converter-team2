Unit Converter

Convert lengths between meters, kilometers, and miles.

About the Project

This project provides length conversion functionality with input validation to handle invalid units, negative lengths, and non-finite values. This project also demonstrates collaborative development, automated testing, and continuous integration using GitHub.

Theme: Unit Converter

Team Members

  • Reda Alalach
  • Hajar Ouaghad

Implemented Features

  • Convert meters to kilometers and miles.
  • Convert kilometers to meters and miles.
  • Convert miles to meters and kilometers.
  • Validate units and reject negative or non-finite lengths.
  • Automated unit tests using pytest.
  • Continuous integration with GitHub Actions.

Getting Started

Clone the repository and enter its directory:

git clone https://github.com/redaalch/unit-converter-team2.git

cd unit-converter-team2

Install the project dependencies:

python3 -m pip install -r requirements.txt

Run the automated tests:

python3 -m pytest

The conversion functions are available in unit_converter/length.py.
